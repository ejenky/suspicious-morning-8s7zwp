# CLAUDE.md

This repo holds the lead-tracker React app (`src/`). It also holds a trading playbook used
in chart sessions.

## Chart sessions (OpenMarket)

When the user asks to map a chart, look for setups, or work on gold, silver or any other
market on OpenMarket, read `trading/PLAYBOOK.md` first and follow it:

- Run the section 8 checklist in order, on the 15m, with weekly/daily for direction only.
- Name the setup and its stage, list which confluence tools agree, or say "no trade" and why.
- Draw on the chart with the conventions in "Mapping onto OpenMarket" at the end of the playbook.
- This is analysis, not financial advice; never place orders unless the user explicitly asks.
